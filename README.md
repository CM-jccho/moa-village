# 🏡 MOA Village v2

작은 마을을 **직접 걸어 다니고, 차를 타고, 미션을 해결하는 오픈월드** PWA.
외부 라이브러리·CDN·서버가 없습니다. 폴더를 그대로 열면 동작합니다.

- 4개 국어: 한국어 · English · 中文 · 日本語 (미번역 키 0)
- 모바일 390px 기준 반응형 + 터치 조이스틱 / 홈 화면 설치(PWA)
- 모든 상태는 브라우저 `localStorage` 에만 저장 (계정·서버 없음)
- 라이브 데모: <https://cm-jccho.github.io/moa-village/>

---

## 바로 실행

```bash
python3 -m http.server 8080
# http://localhost:8080
```

`index.html` 을 파일로 직접 열어도 대부분 동작하지만, `data/trending-items.json` 조회와
PWA 서비스워커는 http(s)에서만 동작합니다. 로컬 서버 사용을 권장합니다.

## 조작

| 동작 | 데스크톱 | 모바일 |

## 기능

### 1. GTA 벤치마크 오픈월드
- **거대한 스크롤 마을**: 5개 구역(중앙 광장 · 상점가 · 주거 · 공원 · 항구), 도로 8개, 횡단보도, 가로등, 분수·부두·무대
- **카메라 팔로우 + 부드러운 줌**: 걸을 때·운전할 때·빠를 때 줌이 다르게 따라붙습니다
- **코너 레이더 미니맵**: 플레이어 중심 회전 없음(North-up), 미션·차량·오너먼트·주민 표시, `M`/🗺️ 로 전체 지도 + 핑
- **테마 마을 4종**: **설강 마을**(눈) · **해바람 언덕**(꽃) · **모찌 항구**(노을) · **별빛 골목**(밤) — 각기 다른 팔레트·프롭 배치
- **날씨 5종**: 맑음 · 비 · 눈 · 노을 · 밤 · 자동(현지 시각 기준). 빗줄기·눈송이·별·가로등 불빛이 함께 바뀝니다
- **동적 상황**: 길을 걷는 주민 13명, 순찰 차량·트램, 반짝이는 수집 요소, 타이어 스키드 자국

### 2. 탈것 6종 (탑승 · 주행 · 하차)
- 미니카 · 슈퍼카 · 자전거 · 스쿠터 · 트램 · 별빛 썰매
- 차량 접근 시 `F` 프롬프트 → 탑승, 속도계 · 경적 · 속도선 · 충돌 흔들림 · 노면/비포장 감속
- 슈퍼카 · 썰매는 **VIP 쇼룸 시승차**(30초 무료)로 누구나 먼저 타 볼 수 있습니다

### 3. 라이브 미션 · 히트(★) 시스템
| 미션 | 내용 |
|---|---|
| 📦 특급 배송 | 상점에서 짐 → 목적지 배달 |
| 🎁 보급 드롭 | 하늘에서 떨어진 상자를 찾아 개봉 (희귀 오너먼트 보너스) |
| 🐾 반려동물 구조 | 길 잃은 펫을 찾아 집까지 에스코트 |
| 🎉 거리 축제 | 축제 구역에 머물며 ★ 게이지 채우기 (불꽃놀이) |

- 미션 완료 · 빠른 주행 · 축제 참여로 **히트 ★1~★5**(Wanted 스타일) 상승, 시간이 지나면 서서히 식습니다
- ★3 달성 또는 보급 상자 개봉 시 **가벼운 미리보기 카드**(강제 팝업 아님)

### 4. 마을 수집 · 꾸미기 (v1 계승)
- 오너먼트 25종 · 등급 일반 / 레어 / 한정판, 마을당 최대 24개 배치
- 바닥을 눌러 배치, 끌어서 이동, 회전·회수·선물
- 펫 4종(몽이·나비·모찌·달토끼)이 따라다니며 말풍선 반응

### 5. 래피드(Rapid) 수익화 접점 4곳 — 플레이를 끊지 않게
1. **실제 상품 연동**: <https://www.latpeed.com/products/VTtxq> (MOA Daily · AI 세팅 팩 ₩9,900) + 마을 전용 세트 3종 + `MOA-TRIAL-2026` 체험 버튼
2. **MOA VIP 쇼룸**: 광장 옆 쇼룸에서 슈퍼카/썰매 **30초 무료 시승** → 종료 시 자연스럽게 "래피드에서 영구 해제" 안내
3. **보급 드롭 · ★3 히트**: 희귀 세트 미리보기 카드 + `[래피드 세트 보기]` / `[계속 플레이]`
4. **친구 공구(5인)**: 40% 인게임 할인 + 래피드 세트 시리얼 배너, HUD 💎 / 쇼룸 / 희귀템 탭 어디서든 1클릭 시리얼 입력
- 세트: 설강 리미티드(₩9,900) · 해바람 레어(₩12,900) · 별빛 나이트(₩14,900)
- 세트 `buyUrl` · `code` 값은 `assets/js/catalog.js` 상단 `RAPID` 블록에서 바꿀 수 있습니다

### 6. 친구 · 공구 · 선물 (v1 계승)
- 추천 코드 `MOA-XXXXXX`, `?ref=CODE` 초대 (+75 코인), `?coop=CODE` 공구 참여, `?gift=...` 선물 수령

### 7. 매시간 유행 아이템 파이프라인
```
data/trending-items.json     ← 앱이 읽는 결과 파일
scripts/update_trends.py     ← Google Trends RSS(KR/US) 조회 → 오너먼트 매칭 → 실패 시 시간 시드 로테이션
.github/workflows/hourly-trends.yml  ← cron '15 * * * *'
```

## 딥링크

| 파라미터 | 동작 |
|---|---|
| `?ref=CODE` | 초대 링크. 최초 방문 시 +75 코인 |
| `?coop=CODE` | 친구 공구 참여 안내 → 참여 시 게이지 +1 |
| `?gift=<payload>` | 선물 도착 연출 → 받으면 내 보관함에 추가 |

## 개인정보 · 저장

- 서버 없음, 계정 없음, 결제 없음
- 닉네임·코인·배치·초대 코드는 브라우저 `localStorage` (`moa.village.v1`)에만 저장
- 초기화: 콘솔에서 `MOA.Store.reset()` 또는 사이트 데이터 삭제

## 프로토타입의 한계 (정직한 범위)

- 친구 초대·공구 참여는 **시뮬레이션**입니다. 실제 친구의 참여는 링크를 연 그 브라우저에서만 반영됩니다(서버 없음).
- 래피드 상품 링크는 실제 판매 페이지지만, 시리얼 코드는 파일에 정의된 값입니다(운영 시 주문번호 해시 등으로 발급).
- 유행 아이템은 공개 RSS + 로테이션 방식이며, 매출·재고와 연동되지 않습니다.
- 결제·배송·계정 기능은 없습니다.
